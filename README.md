# Sistema de Biblioteca Digital

O sistema tem como objetivo gerenciar o acervo de livros físicos e digitais, contemplando empréstimos, devoluções, reservas e histórico de leitura dos usuários.

O projeto adota a **Arquitetura Hexagonal (Ports and Adapters)** e a **Clean Architecture** como abordagens principais, com **Event-Driven** aplicado de forma complementar ao processamento assíncrono de notificações.

## Documentação Arquitetural

A arquitetura é documentada seguindo o **modelo C4**, com diagramas desenvolvidos em **Structurizr DSL**.

**[Visualizar diagramas arquiteturais](docs/architecture/architecture.md)**
